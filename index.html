        What's real on this page

        Live reasoning. Your message goes to this project's own backend (/api/chat), which calls the Claude API with your key kept on the server. The agent only knows the playbook's data and the F.T.T.U catalog, so every partner, price and part it names is one you can check on the playbook page.

        Estimates, labeled. The readiness percentage is the agent's judgment, not a measurement. Partner facts were checked in September 2026 and can change. The agent never makes up a price; anything not in the playbook it calls a quote you need to request.

        What it can't do. It doesn't contact factories, place orders or pay for samples. When it writes a quote request or an email, it comes with a copy button so you send it yourself.

        Marketing lives elsewhere. This agent only covers making the product. Who buys it, and how you reach them, is your marketing agent's job.
